Basics of Compiler Design

Language rules

Types are int and float. Every statement ends with a semicolon.

  • Declare: int marks;
  • Assign: marks = 420;
  • Print: print marks; or print marks / 5;

Expressions use + - * /, brackets and unary signs. Declare and assign a variable before using it. Integer division drops the fraction. An int is widened to float when mixed with a float, and a float can't be assigned to an int. // starts a comment.

Not supported: strings, arrays, functions, loops and conditions.
